# Kemsor inner-page design sample

Standalone Locations & Logistics concept. Open `index.html` directly, or preview at http://127.0.0.1:3010/ while the separate preview server is running.

This folder is independent of the website. It contains its own HTML, CSS, JavaScript, fonts, logo and optimized images; it requires no installation or build.

The design uses the existing Kemsor palette and typography: Inter and Manrope, a 46px desktop page title, 44px desktop section titles, and the website's responsive type scale. Body copy is 16px.

Motion includes a scouting-route illustration, image movement on pointer input, section reveals, a scroll-drawn process route, and service-linked image changes. Use the header motion control to pause animation. System reduced-motion preferences are respected.

The map is decorative, and the supplied images are illustrative artwork. Copy remains sample content for reviewing this design.

Previews: `preview.png` shows the first desktop screen. `preview-desktop.png`, `preview-tablet.png`, `preview-mobile.png`, and `preview-small-mobile.png` show complete layouts.
